# Captured public bibliographic responses

These responses were retrieved for the dated A3/A4 supplement. Each JSON records URL, response status, base64 response body, body SHA-256 and retrieval time. This is real response data, not a hand-written mock. Rate limits, failures and malformed payloads are preserved and counted as incomplete evidence. No authentication, cookies, private browser data or API keys were used. The metadata and service responses retain their original source terms; the project MIT license does not override them.

The source algorithms consume these recorded response bytes on offline re-execution. The manifest is `provenance/http_cache_manifest.json`. CheckIfExist source/license/version are in `third_party/checkifexist`. The original published CSV remains separately CC BY 4.0.
